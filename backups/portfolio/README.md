# Portfolio Evidence Tier

This directory is for public-safe evidence that demonstrates the ERP work without
revealing real customer, project, person, site, price, revenue, cost, or secret
values.

Commit-safe contents:
- Anonymized screenshots with all names and identifiers replaced.
- Aggregate validation summaries.
- Synthetic sample data generated from documented rules.
- Case-study drafts that describe architecture, constraints, and outcomes.

Not allowed:
- Raw Excel files.
- Supabase exports with real rows.
- `.env*`, service-role keys, JWTs, OAuth secrets, or API tokens.
- Real customer names, project names, construction site names, personal names,
  phone numbers, email addresses, exact addresses, or row-level financials.

Put generated public assets under `generated/`; review every file manually before
publishing.
