# 운영 피드백 기록

실배포 후 사용자(현업)에게 받은 피드백과 해결 방법을 한 줄로 요약한 로그.
상세 구현은 git 커밋·PROGRESS.md 참고.

| 날짜 | 피드백 | 수정 방법 (요약) |
| --- | --- | --- |
| 2026-06-24 | 공사현장 입력이 자유 타이핑이라 공사구분·종류(드롭다운)와 통일성 부족 → 드롭다운 필요 | `공사현장` 테이블 신설 + `/admin/sites` 추가·삭제 + 수주 폼 Select 교체(생성순 정렬, '기타' 맨 뒤 고정) |
| 2026-06-24 | 준공 완료해도 달성률이 안 바뀌고, 준공액 ≠ 수주액인데 매출손익은 수주액 기준이라 부정확 | 준공 저장 시 `수주.달성율=100` + `공사이력`에 준공정산 행(성과=준공액공급가−기존누계) 자동 적재 → 매출손익 총성과=준공액. 해제 시 자동 행만 삭제해 직접 입력 이력 무손실 |
