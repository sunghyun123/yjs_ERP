# 해를 넘기지 않는 주 + 최소월 2026-01 (PR-1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 금요일 기준 주차 규칙(`gongmu/_lib/주차.ts`)에 **"해가 바뀌는 주는 1/1에서 자른다"**를 더하고, 볼 수 있는 첫 달을 `2026-01`로 연다. 연간 표(PR-2·PR-4)의 약속 "한 해의 숫자는 그 해 안에 다 있다"를 날짜 규칙 한 곳에서 보장한다.

**Architecture:** 계산은 새로 만들지 않는다. 주의 소속을 정하는 규칙 하나(`주조각`)를 `주차.ts` 안에 두고 `소속월Of`·`달의주목록`·`주목록기간`이 그 규칙만 거친다. 소비자(공무 화면, 매출손익 금요일 표, 대시보드 API)는 **한 줄도 기간을 직접 계산하지 않으므로** 주차.ts만 바뀌면 같이 따라온다. 화면 쪽 변경은 '· 금주' 표시 조건 한 줄뿐이다.

**Tech Stack:** TypeScript · Next.js 16 · vitest

**설계 문서:** `docs/superpowers/specs/2026-11-12-dashboard-yearly-plan-actual-design.md` §3-2, §3-3, §6(게이트 1 결정) · 앞 문서 `2026-11-09-plan-actual-table-and-data-alignment-design.md` §0

**티어:** A (회계 정합성 + 타임존 지뢰 + 다른 레포가 쓰는 API의 범위 변경). 게이트 3~5는 Task 5.

## 결정 사항 (이 계획에서 정함)

1. **자르는 조건은 "월요일과 일요일의 해가 다르다" 하나.** 금요일이 12월이든 1월이든 상관없다.
   - 2026-12-28(월)~2027-01-03 주: 금요일 1/1 → 기존엔 통째 2027-01. 새 규칙: 12/28~31 → **2026-12**, 1/1~1/3 → 2027-01.
   - 2027-12-27(월)~2028-01-02 주: 금요일 12/31 → 기존엔 통째 2027-12. 새 규칙: 12/27~31 → 2027-12, **1/1~1/2 → 2028-01**.
   - 해 경계가 아닌 주는 기존 규칙(금요일의 달) 그대로. 프로토타입 실측: 2025-12~2028-02에서 소속 달이 바뀌는 날은 **9일뿐**(2025-12-29~31, 2026-12-28~31, 2028-01-01~02), 모든 달의 기간이 빈틈·겹침 없이 이어진다.
2. **`주정보` 모양:** `{ 월요일, 시작, 끝, 소속월, 주차, label }`.
   - `월요일` = 그 주의 진짜 월요일. **열쇠 전용**(URL `week=`, `월요일Of(행 날짜)`와 비교, `금주월요일`과 비교). 한 달의 주 목록 안에서는 겹치지 않는다(12/28 열쇠는 12월 목록과 1월 목록에 하나씩 — URL엔 `month`가 같이 붙는다).
   - `시작`/`끝` = 이 달에 들어오는 첫날·마지막 날(**끝 포함**). label·기간은 이것만 쓴다.
   - **`일요일` 칸은 지운다.** 쓰는 곳이 주차.ts 밖에 0곳(grep 확인)이고, 남겨두면 잘린 주에서 거짓말을 한다(12월 조각의 일요일 = 1/3).
3. **`소속월Of(날짜)`** — 인자가 "월요일"에서 "아무 날짜"로 바뀐다. 잘린 주는 날짜가 든 조각의 달. 기존 호출은 전부 주차.ts 안(+테스트)이라 밖에서 깨질 곳 없음.
4. **금주월 = `소속월Of(오늘)`** (`금주소속월기간`·`조회월기간`·`resolve선택` 셋 다). `금주월요일`은 그대로 `월요일Of(오늘)`.
5. **`선택상태`에 `금주월` 추가**, '· 금주'는 `w.월요일 === 금주월요일 && 선택.월 === 금주월`일 때만. 안 그러면 2027-01-02에 12월 화면을 열 때 이미 지난 12/28~31 조각에 '금주'가 찍힌다.
6. **`최소월 = '2026-01'`.** 따라 열리는 곳: 공무 화면 ◀(1월까지), 매출손익 금요일 표 1~8월 숫자, `/api/kpi/monthly-performance?month=` 400 범위. 대시보드는 자기 상수 `MIN_PLAN_MONTH='2026-09'`(yjs_Dashboard `web/home.js:14`)로 막혀 있어 PR-4 전까지 1~8월을 요청하지 않는다 — 이 PR 배포로 대시보드 화면은 안 바뀐다.
7. **'오늘'은 여전히 호출부가 KST로 넘긴다**(`todayKST()`/`formatKST(now)`). 주차.ts는 시계를 읽지 않는다. 연말 KST 00:00~09:00(9시간) 동안 서버 UTC 날짜는 아직 12/31이라, UTC 날짜를 넘기면 1/1 새벽에 금주월이 12월로 잡히고 `?month=2027-01`이 400이 된다 — 테스트로 고정.

```ts
export type 주정보 = {
  /** 그 주의 진짜 월요일 — 열쇠 전용(URL week=, 월요일Of(행 날짜)·금주월요일과 비교). 잘린 주에선 시작과 다르다 */

  /** 이 달에 들어오는 첫날 (잘린 주의 뒤 조각이면 1/1) */
  시작: string
  /** 이 달에 들어오는 마지막 날, 포함 (잘린 주의 앞 조각이면 12/31) */
  끝: string
  소속월: 연월
  /** 그 달 안에서 1부터 */
  주차: number
  /** '1주차 1/1~1/3' — 시작~끝 */
  label: string
}

type 조각 = { 시작: string; 끝: string; 소속월: 연월 }

/**
 * 한 주(월~일)를 해 경계에서 자른 조각. 해를 안 넘으면 1개(금요일의 달), 넘으면 2개(12월·1월).
 * 주의 소속을 정하는 규칙은 이 함수 하나다 — 소속월Of·달의주목록이 모두 여기만 거친다.
 */
function 주조각(월요일: string): 조각[] {
  const 일요일 = addDays(월요일, 6)
  const y = 월요일.slice(0, 4)
  const ny = 일요일.slice(0, 4)
  if (y === ny) return [{ 시작: 월요일, 끝: 일요일, 소속월: addDays(월요일, 4).slice(0, 7) }]
  return [
    { 시작: 월요일, 끝: `${y}-12-31`, 소속월: `${y}-12` },
    { 시작: `${ny}-01-01`, 끝: 일요일, 소속월: `${ny}-01` },
  ]
}

/** 그 날짜가 속한 달 — 해를 안 넘는 주는 금요일의 달, 잘린 주는 날짜가 든 조각의 달 */
export function 소속월Of(ymd: string): 연월 {
  // 조각은 그 주 7일을 빈틈없이 덮으므로 find 는 반드시 찾는다
  return 주조각(월요일Of(ymd)).find((c) => c.시작 <= ymd && ymd <= c.끝)!.소속월
}
```

export function 달의주목록(ym: 연월): 주정보[] {
  const out: 주정보[] = []
  // 이 달에 조각이 걸칠 수 있는 주 = 1일이 든 주 ~ 다음 달 1일이 든 주 (금요일 규칙상 그 밖의 주는 이 달일 수 없다)
  const 마지막월요일 = 월요일Of(`${다음달(ym)}-01`)
  for (let 월요일 = 월요일Of(`${ym}-01`); 월요일 <= 마지막월요일; 월요일 = addDays(월요일, 7)) {
    for (const c of 주조각(월요일)) {
      if (c.소속월 !== ym) continue
      const 주차 = out.length + 1
      out.push({ 월요일, 시작: c.시작, 끝: c.끝, 소속월: ym, 주차, label: `${주차}주차 ${md(c.시작)}~${md(c.끝)}` })
    }
  }
  return out
}

/** 주 목록이 덮는 기간 [from, to) — 첫 주 시작 ~ 마지막 주 끝 다음 날. 월요일(열쇠)로 계산하지 않는다 */
export function 주목록기간(주목록: 주정보[]): { from: string; to: string } {

}
