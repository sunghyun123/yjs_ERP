# 대시보드 연간 표 하단 그래프 (연간 PR-5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** yjs_Dashboard 홈 연간 표 카드(`.home-table-slot`) 바닥에 **가로로 길고 납작한(약 150px) 1~12월 그래프**를 붙인다. 달마다 시공·정산 두 칸, 각 칸은 옅은 계획 막대 위에 진한 실적 막대를 겹친 불릿 모양. 막대는 **바로 위 표의 같은 월 열 아래**에 선다 — 숫자는 표가, 모양은 그래프가 보여 준다("메인은 위의 숫자, 그래프는 참고용").

**Architecture:** 새 API·새 계산 없음. PR-4의 `yearTableState.grid`(5분 갱신)에서 `grid.construction.total.cells` / `grid.settlement.total.cells`만 읽는다. 그래프는 `renderYearTableHome()` 끝에서 **같은 호출로** 그린다 — 표와 그래프가 다른 순간의 데이터를 보일 자리가 없다. 그리기는 HTML/CSS grid + div 높이 %(담당자 막대와 같은 방식, 의존성 0). 표를 `table-layout: fixed` + `<colgroup>`으로 바꿔 그래프와 **같은 열 틀**(CSS 변수)을 공유한다.

**Tech Stack:** 정적 HTML + 바닐라 JS(IIFE, 테스트 러너 없음 → `node --check` + 브라우저 실측).

- 대상 레포: **yjs_Dashboard** (이 문서만 yjs_erp에 둔다 — 앞 PR 문서들과 같은 자리)

### Q5 표시 규칙 (표 ↔ 그래프 같은 말)

| 칸 상태 (`grid` 값) | 표 | 그래프 |
|---|---|---|
| 완료 달 | 숫자 + 실행률 배경 | 옅은 계획 막대 + 진한 실적 막대 |
| 진행 중 (`i === grid.nowIndex`) | 옅은 세로 테두리 + 머리 "진행" | 그 열 옅은 세로 테두리 + 라벨 "진행" (막대 색은 다른 달과 같음) |
| 미래 (`actual === null && !failed`) | 실적 `—` | **실적 막대 없음** — 0 높이 막대도 그리지 않는다. 계획이 있으면 옅은 막대만 |
| 목표 미등록 (`plan === null`) | 계획 `—` | 옅은 막대 없음 |
| 실패 (`failed`) | 실적 `!` + 표 위 알림 줄 | 막대 대신 바닥에 빨간 `!` (설명은 이미 있는 알림 줄이 맡는다) |
| 표 전체 실패 (`grid === null`) | "연간 실적을 불러오지 못했습니다" | **그래프 영역을 숨긴다** — 빈 축만 남기면 "전부 0"으로 읽힌다 |
| 갱신 실패 (`staleSince`) | 직전 표 + "갱신 실패 HH:MM" | 직전 grid로 그대로(같은 호출이라 자동) |

## 부수 결정 (Claude 기본값 — 구현 게이트 2에서 이의 있으면 바꾼다)

- **세로 눈금:** 0부터. 최대값 = 그 해 시공·정산 합계 칸의 계획·실적 중 `null`이 아닌 값의 최대. 최대값이 0(전부 0·미등록)이면 막대 없이 바닥선만. 눈금선은 최대값 한 줄 + 왼쪽 첫 열에 그 값(백만원, `fmtMillion` 재사용)과 "(백만원)". 반올림 상한(예: 500 단위 올림)은 쓰지 않는다 — 최대 막대가 꼭대기에 닿는 게 정직하다.
- **첫 열(표의 '구분' 열 아래):** 범례 — `■ 시공` `■ 정산`(실적 색) + `▭ 계획`(옅은 색) + 눈금 값.
- **합계 열 아래:** 비운다(연간 합계를 같은 눈금에 그리면 월 막대가 전부 납작해진다).
- **색:** 표의 접힘 단추 색을 그대로 — 시공 `#1f6fd6`, 정산 `#2b8a3e`. 계획은 같은 색 약 22% 투명도. 실행률 색(초록/빨강)은 그래프에 쓰지 않는다(표 배경이 이미 말한다).
- **월 라벨:** 그래프 바닥에 작게 `1`~`12`(표가 펼쳐져 머리줄이 멀어졌을 때도 읽히게). 진행 달은 `11 진행`.
- **높이:** 그래프 영역 약 150px(라벨 포함). Task 0 실측이 접힘 표 + 150px를 카드 안에 못 넣으면 120px까지 줄이고 기록.
- **좁은 화면(기존 반응형 구간):** 그래프는 그대로 둔다. `table-layout: fixed`라 표가 가로로 넘치지 않아 열 틀이 유지된다(넘치면 정렬이 깨지는지 Task 4에서 한 번 확인).
- **접근성:** 그래프 컨테이너 `role="img"` + `aria-label="1~12월 시공·정산 계획 대비 실적 막대그래프(숫자는 위 표)"`.
